# Rohan Ondkar — Motorsport Home

Bruno Simon–inspired 3D homepage: a modern motorsport house, a driveway GT, and lighting that follows **America/New_York (EST/EDT)**. Background FX change with the period (stars, mist, clouds, heat, embers, fireflies).

## Develop

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Publishes to [rohanondkar.github.io](https://rohanondkar.github.io).
